# День 1: Linux — база

## Что такое Linux
- ОС, открытая, серверная, терминальная.
- 90% серверов в мире.
- Основа облаков (AWS, Azure).

## Команды

### Навигация
- `pwd` — где я
- `ls` — что в папке
- `cd` — перейти

### Файлы
- `mkdir` — создать папку
- `touch` — создать файл
- `cp` — копировать
- `mv` — переместить
- `rm` — удалить

### Права
- `chmod` — изменить права
- `sudo` — от root

### Процессы
- `ps aux` — все процессы
- `top` — живые
- `kill` — убить

### Сеть
- `ip a` — IP-адреса
- `ping` — проверить связь
- `curl` — HTTP-запрос

## Что понял
- Linux — база для Cloud.
- Терминал — главный инструмент.
## Практика (что делал руками)

### Навигация
- `cd -` — вернуться в предыдущую папку (удобно!)
- `ls -la` — вижу скрытые файлы

### Файлы
- `>>` — добавить в файл (не перезаписать)
- `rm -rf` — удалить папку с содержимым (ОСТОРОЖНО!)

### Права
- `-rw-r--r--` — обычный файл
- `-rwxr-xr-x` — исполняемый
- `chmod +x` — сделать исполняемым

### Процессы
- `ps aux | head -10` — первые 10 процессов
- `top` — живые (q — выход)
- `grep` — фильтр

### Сеть
- `ip a` — IP-адреса (inet 192.168...)
- `ping -c 4` — 4 пакета
- `curl -I` — только заголовки

### Поиск
- `grep "текст" файл` — найти текст
- `find путь -name "*.md"` — найти по имени
- `find путь -type d` — найти папки

## Что понял
- Практика = 80% обучения.
- Терминал — быстро и мощно.
- `man команда` — справка (например `man ls`).
