Вверх = cd .. (родительская папка)
Вниз/Внутрь = cd имя_папки (дочерняя папка)
Назад = cd - (история переходов)
Домой = cd или cd ~

ВАЖНО структура роботает cd (..  ~) enter + pwd роботает блоком

/etc конфиги системы
ls | head -20 показывает 20 первых строк заголовков | нужно пробелы с 2 сторон
/var — изменяемые данные (кэш, логи)
/var/log — тут лежат сами логи

ВАЖНО: В Linux можно и нужно передавать командам сразу полный путь к вложенным папкам (например: папка/папка/папка/файл)
пример ls /var/log | head показывает заголовки логов

/tmp временное
/usr програмы
/bin основные иполняемые
tree -ветки
tree /home показывает ветви файлов (легче найти что то
uptime -сколько времени в этом посещении линукса и тп
lscpu 1 командой характеристики железо пкноута
clear очевидно очистить комбинация Ctrl+L
ls -l (тоже самое что ls только больше инфы)
echo $PATH показывает директории в которых ищет команды
echo - вывод текста (например, echo hello world выведет на экран: hello world)
ctrl+alt+f2.3.4.5... линукс без графики чисто управление строкой команда  ctrl+alt+f1 выход
man -k (слово) искать все команды связанные с ним
man (команда) по команде мануал
