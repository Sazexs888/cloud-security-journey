# День 3: Файлы и папки

- `cp` копировать (для файлов)
- `cp -r` копировать (для папок)
- `touch` создание файлов 
- `mkdir` создание папок

- `-r` для папок
- `-rf` удаление без подтверждения папки (ОПАСНО!)
- `-f` удаление без подтверждения файлы 

- `echo xdd > file.txt` запись c 0 xdd в file.txt
- `echo xdd123 >> file.txt` добавление xdd123 в file.txt, записывает с новой строки
- `cat file.txt` чтение

- `mv` переименовать (также используется для перемещения файлов/папок)
- `rm` remove\удалить 
- `rm -r` удалить папку (с содержимым)
- `mkdir -p` создать вложенные папки (например, `mkdir -p a/b/c`)
