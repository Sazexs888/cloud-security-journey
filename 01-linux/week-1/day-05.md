# День 5: Поиск файлов и перенаправление

## 1. Команда find (поиск файлов)
- `find /` — искать по всей системе (от корня).
- `-name "*.txt"` — искать по имени. Звездочка `*` означает "любые символы".
- `-type d` — искать только папки (d = directory).
- `-type f` — искать только файлы (f = file).
- `-size +10M` — искать файлы больше 10 МБ (+ = больше).
- `-size 1033c` — искать файл ровно 1033 байта (c = characters/байты).
- `-mtime -1` — искать файлы, измененные за последние сутки (-1 = меньше 1 дня назад).

## 2. Which и Whereis (где программа)
- `which dota2` — показывает путь к программе (где находится исполняемый файл).
- `whereis ls` — показывает, где бинарник (сама программа) и где мануал (справка).

## 3. 2>/dev/null (мусорка для ошибок)
- Если ищешь по всей системе (`find /`), ты будешь натыкаться на папки, куда нет доступа (например, `/root`).
- Система будет спамить ошибками `Permission denied`.
- `2>/dev/null` — это команда, которая берет все эти ошибки (поток 2) и выкидывает в "черную дыру" (`/dev/null`), чтобы они не засоряли экран.
- **Важно:** результаты поиска (файлы) остаются, а ошибки (мусор) исчезают.

## 4. Пайп (|) и head
- `find / -name "*.conf" 2>/dev/null | head` — знак `|` (пайп) передает результат одной команды в другую.
- `head` показывает только первые 10 строк. Нужен, чтобы не смотреть на тысячи файлов и не ждать, пока экран прокрутится.

## 5. Что понял
- `find` ищет файлы (по имени, размеру, типу, дате).
- `grep` ищет текст внутри файлов (не путать!).
- `2>/dev/null` — это фильтр от ошибок доступа.
- Регистр букв важен: `Desktop` и `desktop` — разные папки.
