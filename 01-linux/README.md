# Блок 1. Linux (5 недель)

**Цель:** уверенно работать в терминале Linux.
**Время:** 2–3 ч/день, 5 недель.
**Результат:** тест в конце, переход к сетям.

## Структура

- `week-1/` — Терминал и файлы
- `week-2/` — Процессы и пакеты
- `week-3/` — Сеть и файлы
- `week-4/` — Bash скрипты
- `week-5/` — Проекты и закрепление
