## Day 2: Python Data Structures & Hardcore Debugging
- **Lists (`[]`)**: Ordered arrays. Elements are accessed by index (starting from 0).
- **Dictionaries (`{}`)**: Unordered "Key: Value" structures. Used to store detailed host info.
- **Debugging**: Practiced reading Tracebacks. Fixed `SyntaxError` (missing commas, unclosed brackets), `KeyError` (wrong key names), and f-string quote conflicts.
- **Mindset**: Switched prints and logs to English. Dictionaries are data structures, not libraries!
